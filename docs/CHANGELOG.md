# Changelog

## 1.0.0 - 2026-11-07

- Rebuilt the legacy PyQt prototype as the local Helmet Workbench web product.
- Added employee management, face sample collection, CNN training and model activation.
- Added photo, video and camera helmet detection.
- Added camera business mode with daily attendance and violation records.
- Migrated the legacy Tiny YOLO weights to a versioned Keras runtime artifact.
- Added SQLite metadata storage, Alembic migrations, persistent jobs and local evidence retention.
- Added Python, React, API, database and Playwright test coverage.
- Replaced the original repository layout with a clean engineering structure and bilingual documentation.
